# Digital Design Practice

A collection of digital design problems and experiments focused on **RTL, computer architecture, verification, and hardware design**.

Each file represents a problem or concept that I have implemented, tested, or explored while developing my digital design skills.

## Topics

- Digital Logic
- RTL Design
- Verilog / SystemVerilog
- Computer Architecture
- FSMs & Sequential Logic
- Pipelining
- Memory & Caches
- Hardware Design
- Verification & Testbenches
- FPGA Design
- ASIC Design Concepts
